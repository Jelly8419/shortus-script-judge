## 남은 일

1. **귀속·범위 전용 검사**: 원문에서 "누가 무엇을 말했나", "이 숫자는 무엇의 숫자인가"를 먼저 목록으로 뽑고 대본과 비교하는 별도 호출. 지금은 대본 문장에서 출발해 원문을 찾는 방향이라 비슷한 인물·범위 사이의 차이를 놓친다.
2. **완전히 새로운 기사로 검증**: 주입 세트는 원문이 개발셋과 같다.
3. **품질 점수 보정**: 기준 예시(1점/3점/5점 대본)를 프롬프트에 넣거나 사람 점수와 비교. 지금은 변별력이 없어 참고용.
4. **인용 검증 기준 조정**: 두 문장에 걸친 정당한 인용을 놓치는 경우(i07).
5. **영상 입력 흐름**: 구간 선택 판정기는 별도 설계 필요 (D4).
6. **업로드 주체에 따른 기준**: 제품 소개 대본은 브랜드가 올리면 문제없지만 개인 크리에이터가 올리면 광고 문구를 자기 주장처럼 말하게 됨. 판정기는 업로더를 모른다.
7. **저작권 위험 진단**: 대본이 원문 문장을 얼마나 그대로 가져왔는지(원문 문장과의 유사도·직접 인용 비율)를 진단으로 표시. 사실만 추려 새로 쓴 요약은 위험이 낮지만 원문 문장을 그대로 읽으면 복제에 가까워진다. 쇼더스는 원본 권리 책임을 이용자에게 두고 있어, CP 계약 없이 아무 기사나 넣는 일반 사용자에게 특히 필요하다. 섹션 반복 진단에 쓰는 유사도 계산을 재사용하면 된다 (s04 3번째 섹션은 기사 제목을 거의 그대로 반복).
