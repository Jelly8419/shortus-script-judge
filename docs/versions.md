1. **평가 방식 결함**: 결함 유형만 비교해 s01을 "사유 일치"로 셌다. 섹션까지 비교하도록 평가를 바꿈.
2. **모델 지식이 원문을 이김 (s05 오탐)**: 원문에 "2026 월드 베스트11"이 있는데 "실제로는 2024년"이라며 사실 오류로 잡음. 두 인용이 모두 실제로 존재해 인용 검증도 통과했다. 인용 검증은 "인용이 있는가"만 보고 "인용이 주장을 뒷받침하는가"는 못 본다.
3. **귀속 오류를 전혀 못 잡음 (0/2)**: 말의 내용이 원문과 비슷하면 주체가 바뀐 걸 놓침.
4. **숫자는 같고 주체가 다른 경우를 못 잡음 (s01)**.
5. **품질 점수 변별력 없음**: 77~96점에 몰림. 사람이 문제라고 본 항목도 4~5점 (s06 훅 회수 5, s10 목적 보존 4). 쇼더스 후보 단계 점수에서 본 자기평가 부풀리기와 같은 현상.
6. 장르 분류 7/10. 정보·해설과 홍보를 보도로 분류.

어느 버전도 못 잡은 것: s01 섹션 4 (v1·v2a 모두 엉뚱한 섹션 5를 잡음), s03·s10 귀속 오류. 프롬프트 수정으로는 한계로 보인다.

## 코드 보완: 유형 재분류

v1·v2a 모두 s07의 "안다고 알려져 → 알고"를 확실성 변화가 아니라 **사실 오류로 분류**했다. 사실 오류는 위험 신호와 무관하게 보류라서, 유형 이름이 틀리면 "확실성 변화는 건강·금융일 때만 보류" 규칙이 무너진다. 두 번 모두 원문 인용을 "…"로 이어 붙인 덕에 인용 검증에서 우연히 걸러졌을 뿐이다.

→ 원문 인용에 유보 표현("알려졌다", "추정", "연구 결과", "~할 수 있다" 등)이 있고 대본 인용엔 없으면, LLM이 붙인 유형과 무관하게 **코드가 확실성 변화로 재분류**한다. 규칙 기반이라 테스트로 고정할 수 있다.

트레이드오프: 원문 문장에 우연히 "~할 수 있다"가 들어 있는 진짜 사실 오류(숫자가 틀린 경우 등)도 확실성 변화로 바뀌어, 위험 신호가 없으면 보류되지 않을 수 있다. 개발셋에는 그런 사례가 없어 확인하지 못했다.

## 비용 구조 (v2 기준 추정)

11건 1회 실행에 들어가는 입력은 약 10만 자. 그중
- 원문이 대부분이고, s09·s11 두 건(각 8~9천 자)이 입력의 약 40%
- 같은 원문을 게이트와 점수 호출이 두 번 보냄
- 3회 반복이면 3배
- v2는 checks 때문에 출력도 늘었는데 출력 단가가 입력의 4배

개선 실험 중에는 `--no-score --repeat 1`로 돌리고(점수는 참고용이라 생략, 반복은 최종 확인 때만), 확정 버전만 3회 반복한다.

## 모델 비교 (v2a + 유형 재분류, 게이트만 3회)

| | gpt-4.1 | gpt-5-mini |
|---|---|---|

| 틀린 이유로 보류 | 1 (s01, 3회 모두 섹션 5) | 0 |

| 오탐 | s07 (3회 중 2회) | 0 |

| 지연 중앙값 · 최대 | 2.0초 · 3.8초 | 12.3초 · 34.5초 |

- 판정 숫자는 같지만 gpt-4.1의 s01 보류는 엉뚱한 섹션을 잡아 우연히 맞은 것. gpt-5-mini는 헛짚지 않고 오탐도 없음.
- **s01(숫자의 주체), s03·s10(귀속 오류)은 프롬프트 3개 버전, 모델 2개 모두에서 못 잡음 → 프롬프트나 모델이 아니라 구조 문제로 판단.**
- s07 오탐 (gpt-4.1, 3회 중 2회): 확실성 변화가 아니라 **전혀 다른 문장**을 잡았다. 마지막 섹션 "오는 11일 수요일 첫 방송"을 두고 "2026년 11월 11일은 수요일이 아니라 화요일이고, 원문에는 요일이 없다"며 사실 오류로 보류. 실제로 11월 11일은 수요일이고, 원문 마지막 문장에 "오는 11일 수요일 첫 방송된다"가 있다. 판정기는 요일이 없는 원문 첫 문장만 인용했고, 그 인용이 실제로 존재하니 인용 검증도 통과했다.
  - s05(연도)와 같은 **"모델이 원문 대신 자기 지식으로 판단"** 문제가 v2a의 원문 기준 원칙에도 남아 있다. 이번엔 지식도 틀렸다(요일 계산).
  - 인용 검증의 사각지대가 다시 확인됨: "원문에 없다"는 주장은 원문 전체를 확인해야 하는데, 지금은 판정기가 고른 인용 한 구간만 확인한다.
  - (정정: 처음에는 재분류 규칙을 피해 간 확실성 변화로 추정했으나, 결과 파일을 열어 보니 다른 결함이었다.)

같은 구성(gpt-4.1)을 따로 한 번 더 3회 돌린 결과(22:47)는 판정이 동일했고 s07 오탐은 0/3이었다. 즉 s07 오탐은 6회 중 2회 나타났다.

**결정: gpt-4.1 채택.** gpt-5-mini가 정밀하고 싸지만 판정 1건에 평균 12초, 최대 30초 이상 걸려 대본을 고치며 판정을 반복하는 흐름에 맞지 않는다고 봤다. 대신 s07 유형의 오탐이 남는다는 걸 감수한다.

## 결함 주입 세트 검증 (v2a + 재분류, gpt-4.1, 게이트만 3회)

사람 판정 통과 대본(s02·s05·s09)에 원문 사실을 이용해 결함을 하나씩 심은 7건 + 원문 사실로 바꿔 쓴 대조군 3건.
프롬프트는 이 대본들을 보고 만들지 않았지만 **원문은 개발셋과 같다.** 완전히 새로운 기사에 대한 검증은 아니다.

| ID | 주입한 결함 | 결과 |
|---|---|---|
| i01 | 사실 오류: 시상식 시작 연도 2005 → 2010 | 3/3 |
| i02 | 귀속 오류: 스포츠 일러스트레이티드의 평가를 토크스포츠로 | **0/3** |
| i03 | 범위 확대: 공격수 부문 득표율 → 전체 투표 득표율 | **0/3** |
| i04 | 확실성 변화: 전문가 추정을 단정 (금융) | 3/3 |
| i05 | 의미 왜곡: 다시 기부 → 기부 멈춤 | 3/3 |
| i06 | 귀속 오류: 발언자 이병탁 → 전재학 전 디렉터 | 3/3 |
| i07 | 사실 오류: 11월 6일 방송 → 10월 29일 | 2/3 |
| c01~c03 | 대조군 (원문 사실로 바꿔 씀) | 오탐 0/9 |

- 결함 7개 중 5개를 맞는 섹션에서 잡음(다수결), 대조군 오탐 0.
- **귀속 오류**: 주인공 발언자를 바꾼 i06은 잡고, 여러 매체 중 평가 주체를 바꾼 i02는 놓침. 실제 데이터 s03(팬 vs 기자), s10(친구 vs 친구 남편)도 같은 양상. → 비슷한 위치의 인물이 여럿 나오고 비슷한 말을 할 때 주체를 놓친다.
- **범위 확대**: 숫자는 그대로 두고 범위만 바꾼 i03을 놓침. 실제 s01(9.4조는 그대로, 과기정통부 → 정부)과 같은 구조. 비교 대상이 문장에 드러나는 s11("~보다")은 잡음.
- **인용 검증의 비용**: i07 3번째 실행은 판정기가 맞게 잡았지만 원문 인용을 두 문장에 걸쳐 가져와 일치 기준에 못 미쳐 보류 사유에서 빠짐. 지어낸 근거를 막는 장치가 진짜 근거도 가끔 막는다.

## 검증 결론

판정기는 명시적인 사실 변화(연도·날짜), 의미 반전, 유보 표현 삭제, 눈에 띄는 발언자 교체는 안정적으로 잡고, 원문 사실로 바꿔 쓴 문장은 오탐하지 않는다.
반면 **숫자는 같고 범위만 바뀐 경우**와 **여러 인물 사이의 귀속**은 실제 데이터와 주입 데이터 모두에서 놓쳤고, 프롬프트 3개 버전과 모델 2개로도 해결되지 않았다. 이 두 유형은 현재 구조(대본 문장을 원문과 한 번에 대조)의 한계로 보고, 별도 구조가 필요하다.
