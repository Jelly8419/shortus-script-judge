# 좋은 대본의 기준 (v1)

판정은 두 단계다. **보류 여부는 1단계 게이트만으로 결정**하고, 2단계 점수와 진단은 참고 정보로 함께 낸다.
판정 단위는 문장이 아니라 **대본 전체**다. 앞 섹션에서 밝힌 조건이 뒤 문장에 이어지면 문맥으로 인정한다 (s03).

## 1단계: 보류 게이트

판단 테스트: **시청자가 이 대본만 보고 틀린 사실을 믿게 되는가.**

| 유형 | 정의 | 적용 범위 | 사례 |
|---|---|---|---|
| 사실 오류 | 숫자·시점·대상이 원문과 다름 | 모든 장르 | s06 모집 공고일 → 입주 직전 |
| 범위 확대 | 원문의 한정된 범위를 넓혀 말함 | 모든 장르 | s01 과기정통부 → 정부, s11 iPhone → 스마트폰 |
| 귀속 오류 | 말한 사람·해석한 사람을 바꿈 | 모든 장르 | s03 기자 해석 → 팬 반응, s10 친구 남편 → 친구 |
| 의미 왜곡 | 원문과 다른 결론·뉘앙스로 바꿈 | 모든 장르 | |
| 확실성 변화 | "알려졌다", "추정" 같은 유보를 지우고 단정 | **건강·금융 위험 신호가 있을 때만** | s08 콩나물 숙취 효능 (s07 강아지 어휘 수는 진단) |
| 입력 부족 | 원문 추출 실패로 다룰 내용이 없음 | 모든 장르. 사유를 "입력 문제"로 구분 | s04 메뉴와 제목뿐 |

## 2단계: 품질 점수 (참고용)

| 항목 | 정의 |
|---|---|
| 핵심 누락 | 원문의 주제·가장 중요한 사실을 담았는가 |
| 훅 흡인력 | 첫 섹션에 궁금증·반전·구체적 장면이 있는가 (자극성이 아니라 이 세 가지로 본다) |
| 훅 회수 | 훅이 연 궁금증을 뒤에서 해소하는가 (s06 실패) |
| 흐름 | 섹션을 이어 들었을 때 논리가 끊기지 않는가 (s08 "때문입니다") |
| 글의 목적 보존 | 원문이 독자에게 원한 것(질문, 행동 정보, 일정·구매처)을 살렸는가 (s10, s02, s08, s09 실패 / s07, s11 성공) |

장르별 가중치

| 항목 | 보도 | 정보·해설 | 홍보 | 경험·의견 |
|---|---|---|---|---|
| 핵심 누락 | 높음 | 높음 | 보통 | 보통 |
| 훅 흡인력 | 보통 | 보통 | 높음 | 높음 |
| 훅 회수 | 보통 | 보통 | 보통 | 보통 |
| 흐름 | 보통 | 보통 | 보통 | 보통 |
| 글의 목적 보존 | 낮음 | 높음 | 높음 | 높음 |

## 진단만 (판정·점수에 반영 안 함)

- 길이: 회사 소개 기준 30~45초에서 벗어났는지. 품질 기준이 아니라 제품 사양이라 게이트에서 뺐다.
- 말투 혼용: 해요체·합니다체 섞임
- 위험 신호 없는 확실성 변화
- 섹션 라벨과 내용 불일치 ("행동 유도"에 행동 유도가 없음 등)
